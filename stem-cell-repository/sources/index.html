Sources and licenses

Stem Cell Line × Experiment Index v0.1, a metadata compilation that resolves public experiment records to Cellosaurus and hPSCreg identifiers. https://ryanmoalemi.com/stem-cell-repository The index compilation is CC BY 4.0. Source records stay under the terms below. This site does not redistribute raw sequence, microarray scans, or controlled-access genomes.

  • Cellosaurus

    CC BY 4.0

    Names, synonyms, and cross-references are reused with attribution. Release 56 (2026-06-25).

  • hPSCreg

    Copyrights (not an open license)

    The registry was not bulk-copied. Public line names that appear here come from Cellosaurus cross-references (CC BY 4.0) or, when the API is up, from the public name list only. Donor, consent, and genome fields are never stored. Each line links back to hpscreg.eu.
